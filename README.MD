# PROJETO LAVAJATO

Projeto desenvolvido em Python para gerenciar um lavajato

Este repositório contém um sistema simples de gerenciamento de um lava-jato
escrito em Python. O objetivo é facilitar o controle de clientes, veículos,
agendamentos e tipos de lavagem através de arquivos JSON e scripts
organizados em módulos. Funcionalidades principais:

- Cadastro e listagem de clientes
- Cadastro e listagem de veículos
- Criação e edição de agendamentos
- Gestão de tipos de lavagem e preços

Estrutura básica:

- Arquivos principais: `main.py`, `sistema_lava_jato.py` e scripts auxiliares
- Dados persistidos em: `clientes.json`, `carros.json`, `agendamentos.json`, `tipos_lavagem.json`

Como executar:

1. Certifique-se de ter Python 3 instalado.
2. Execute `python3 main.py` ou `python main.py` na raiz do projeto.

O projeto é leve e destinado a estudos e pequenos usos locais. Contribuições
são bem-vindas — abra uma issue ou um pull request com melhorias.
